# Transfer Learning with PyTorch
I created this repo to show a website that I created that implements a fine-tuned GPT2 architecture that was build from scratch to classify between spam and not spam emails.
Here is the link to the website:
 - https://classifyingspamllm-oliversundaram.streamlit.app/
 
## Instructions

 - Open the link
 - The website may ask you to "wake it up", this is just because it has been inactive for a while
 - Type in some input text in the box, and click "run inference"
 - One clicked, the text will get tokenized, passed through the model, and give you a label of its prediction along with the models confidence

## Warning
This is not a classifying tool with 100% accuracy. Use at your own discretion.
